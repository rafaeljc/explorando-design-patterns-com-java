
# Descrição do Desafio

Chegamos à última etapa da nossa jornada! Agora é o momento de consolidar tudo o que aprendemos sobre Padrões de Projeto (Design Patterns). O objetivo é que você explore esses conceitos na prática e entregue algo que agregue valor ao seu portfólio.

# O Que Entregar?

Sabemos que cada pessoa tem um ritmo e uma forma diferente de aprender. Por isso, sinta-se à vontade para escolher a abordagem que te deixa mais confortável:

- **Reproduzir e Evoluir:** Você pode replicar o projeto que criamos em aula e incluir melhorias ou toques pessoais para deixá-lo com a "sua cara";

- **Criar do Zero:** Se sentir confiança, desenvolva uma nova ideia ou API totalmente nova aplicando os padrões vistos (seja com Java Puro ou com a produtividade do Spring);

- **Focar em um Padrão:** Se você está começando e não quer criar um projeto complexo agora, não tem problema! Você pode escolher um padrão específico (como o Chain of Responsibility, por exemplo) ou apenas reproduzir os exemplos de Java Puro para fixar o conhecimento.

Para te ajudar nessa missão, lembre-se destas dicas:

- **Pesquise Referências:** Digite no Google "java design patterns github" ou "java design patterns examples". Isso vai te dar vários insights e implementações de referência para estudar;

- **Use o GitHub:** Dê um fork nos repositórios oficiais do laboratório para ter uma base e começar a evoluir seu código a partir dali.
